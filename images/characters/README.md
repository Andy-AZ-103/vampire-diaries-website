# Character Images

Place character images in this directory with the following naming convention:

- `elena-gilbert.jpg` (or .png, .webp)
- `stefan-salvatore.jpg`
- `damon-salvatore.jpg`
- `caroline-forbes.jpg`
- `bonnie-bennett.jpg`
- `jeremy-gilbert.jpg`

## Image Recommendations

- **Recommended size**: 400px - 800px width
- **Aspect ratio**: 3:4 or 4:5 (portrait orientation works best)
- **Format**: JPG, PNG, or WebP
- **File size**: Optimize for web (under 500KB recommended)

The images will be automatically displayed on each character's individual page.
